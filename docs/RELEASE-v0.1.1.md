Install **Kick-Android-TV-Patcher.apk** on your Android TV, or open **Updates** in patcher 0.1.0 and approve the update. The patcher keeps its signing key when updated in place.

This release patches **Kick Android TV 1.12.0 (build 211)**. Select **Get original APKM** for the dual-ARM, 320 dpi, Android 8.0+ variant, then choose the downloaded file in **Patch**. For the previous Kick 1.11.0 profile, see [patcher 0.1.0](https://github.com/PREMIUMSMART-MOD/kick-android-tv-mod/releases/tag/v0.1.0).

The 1.12.0 profile retains the audio compressor, raid navigation, category preferences and live latency controls. The main player applies your selected latency target; MultiView retains its own playback settings.

The Java decoder reconstructed all 926 output entries byte for byte against the tested 1.12.0 mod. See the [validation notes](https://github.com/PREMIUMSMART-MOD/kick-android-tv-mod/blob/v0.1.1/docs/TESTING.md).
